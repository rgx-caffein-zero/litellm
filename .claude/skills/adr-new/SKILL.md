# ADR の作成

## 1. 番号とファイル名

```sh
ls docs/adr/
```

- 既存の最大番号 + 1 を、4 桁のゼロ埋めで使う（例: `0007`）。
- ファイル名は `NNNN-<kebab-case-title>.md`。タイトルは決定の内容を表す（例: `0007-use-postgresql-for-order-storage.md`）。

## 2. 内容

`docs/adr/0000-template.md` をコピーし、すべての節を埋める。

- **背景**: 何が問題で、なぜ今決めるのか。制約を含める。
- **検討した選択肢**: 最低 2 つ。「何もしない」も選択肢になりうる。各選択肢の利点と欠点を、公平に書く。
- **決定**: 採用した選択肢と、比較に基づく理由。
- **影響**: 受け入れるトレードオフと、必要になる作業。
- **見直しの条件**: どうなったらこの決定を見直すか。

事実と意見を区別し、確認していない数値や性能を書かないでください。
決定者・日付など、分からない項目はユーザーに確認してください。ステータスは、ユーザーが承認するまで「提案中」にします。

## 3. 索引の更新

`docs/adr/README.md` の一覧表に行を追加する。
既存の ADR を置き換える場合は、古い ADR のステータスを「NNNN により置き換え」に更新する（それ以外の本文は書き換えない）。
